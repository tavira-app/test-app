# Requirements summary

Backend scope follows Khodroban specification §§1–17 and the analyst contract;
no frontend is included. Planned modules cover catalog, authorized listing
ingestion and history, deduplication, search and alerts, asking-price analysis,
itemized TCO, risk, inspections, comparisons, feedback, assistant/MCP, and operations.

Quality targets remain open decisions. External providers require configurable,
authorized integrations; test fixtures must be explicitly labeled synthetic.
